# tasks/

Working files for planning and self-correction.

## What belongs here

- `todo.md` — the current plan as checkable items, progress marks, and a review section when work is finished.
- `lessons.md` — patterns learned from corrections, written as rules that prevent the same mistake.

## Rules for this folder

- Write the plan to `todo.md` before non-trivial work and mark items off as they are completed.
- Update `lessons.md` after any correction from the user; review it at the start of a session.
- Record open decisions here until settled; settled ones move to the root `CLAUDE.md`.
